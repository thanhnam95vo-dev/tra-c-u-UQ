# Chương trình đồng hành cùng Điểm ủy quyền

## Thời gian cập nhật

Dữ liệu được tổng hợp từ **0h ngày 01/08/2026 đến hết ngày 31/08/2026**.

## Số liệu chính

- Tổng Điểm ủy quyền: **277**
- Tổng thuê bao PTM: **2.201**
- Thuê bao PTM từ 70K: **1.379**
- Tổng doanh thu: **266.234.000 đồng**
- Điểm ủy quyền có PSSL: **249**
- Điểm ủy quyền PSSL có gói từ 70K: **220**

## Nội dung hiển thị

- Hai tab **Tổng quan** và **Theo dõi 22 địa bàn** tiếp tục được ẩn.
- Tab **Tri ân 25/8** hiển thị kết quả chính thức gồm 10 Điểm ủy quyền đạt giải.
- Tab **Tra cứu ĐUQ** sử dụng dữ liệu chốt hết ngày 31/08/2026.
- Số liệu hiển thị được tính lại từ các đơn hàng có trạng thái `Thành công` trong đúng khoảng thời gian chốt; thông tin Điểm ủy quyền lấy từ sheet `TH`.

## Cách sử dụng

Mở file `index.html` bằng Chrome, Edge hoặc Brave. File hoạt động độc lập, không cần kết nối Internet.

Nguồn dữ liệu: `ĐUQ chốt(6).xlsx`.
