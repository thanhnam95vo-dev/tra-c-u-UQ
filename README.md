# Chương trình đồng hành cùng Điểm ủy quyền

## Thời gian cập nhật

Dữ liệu được tổng hợp từ **0h ngày 01/08/2026 đến 11h ngày 20/08/2026**.

## Số liệu chính

- Tổng Điểm ủy quyền: **268**
- Tổng thuê bao PTM: **1.180**
- Thuê bao PTM từ 70K: **633**
- Tổng doanh thu: **118.814.000 đồng**
- Điểm ủy quyền có PSSL: **201**
- Điểm ủy quyền PSSL có gói từ 70K: **134**

## Nội dung hiển thị

- Hai tab **Tổng quan** và **Theo dõi 22 địa bàn** tiếp tục được ẩn.
- Tab **Tri ân 18/8** được giữ nguyên nội dung và kết quả.
- Tab **Tra cứu ĐUQ** sử dụng dữ liệu mới nhất đến 11h ngày 20/08/2026.

## Cách sử dụng

Mở file `index.html` bằng Chrome, Edge hoặc Brave. File hoạt động độc lập, không cần kết nối Internet.

Nguồn dữ liệu: `20. Chương trình đồng hành cùng Điểm ủy quyền luc.xlsx`.
