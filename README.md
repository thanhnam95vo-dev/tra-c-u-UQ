- Hai tab **Tổng quan** và **Theo dõi 22 địa bàn** tiếp tục được ẩn.
- Tab **Tri ân 18/8** được giữ nguyên nội dung và kết quả.
- Tab **Tra cứu ĐUQ** sử dụng dữ liệu cập nhật đến 13h ngày 24/08/2026.
- Số liệu hiển thị được đối chiếu và lấy khớp theo tổng hợp trên sheet `TH` của file chốt.
